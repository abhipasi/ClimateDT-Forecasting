# Data

This repository uses the following climate datasets:

- CHIRPS v3 Daily Reanalysis precipitation
- ERA5-Land Daily Aggregated temperature

Study region: Maharashtra, India.

Study period: 1 July 2016 to 30 June 2026.

Number of spatial sampling locations: 23.

The merged raw dataset contains 83,996 date-location observations.

Large processed CSV files are not stored in this GitHub repository.
They will be archived separately in the associated research-data repository.

The boundary directory contains the Maharashtra boundary shapefile used
for generating the study-area figure.
